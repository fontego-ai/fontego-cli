# Contributing to Fontego

Issues and pull requests are welcome. To set up the project and run the tests, see `AGENTS.md`.

## The contributor agreement

Before your first contribution is merged, you accept the Fontego Contributor License Agreement (`CLA.md`). It takes
one step: the CLA bot asks you in your first pull request. You only do it once.

What it means for you:

- **Your contribution stays yours.** You give Fontego a license to use it; you don't give it away, and you can use it
  for anything else.
- **It lets Fontego move on.** Future versions can change license, and the project can pass to a company or a
  foundation, without asking every contributor again. Versions already released keep their license.

If you contribute as part of your job, make sure your employer allows it (section 4 of the agreement).
